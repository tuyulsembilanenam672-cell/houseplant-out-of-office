The funniest out-of-office auto-reply a houseplant would send, for the make.fun bounty "The Houseplant Out-of-Office".

> "Out of office. I have not been watered since March, I have outlived three managers, and I am still here."

The program writes that one line (104 characters) to `/output/entry.txt`.
